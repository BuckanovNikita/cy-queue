# Документация cy-queue

Указатель всех страниц документации `cy-queue`.

## С чего начать

- [Главная страница](../README.md) — что такое cy-queue и кратчайший путь к первому [заданию (job)](../GLOSSARY.md#job).
- [Подготовка хоста](setup.md) — установка рядом с CY, `queue.toml`, выбор каталогов, несколько пользователей, обновление.
- [Глоссарий](../GLOSSARY.md) — термины очереди и их русские названия.

## Команды

- [`cy-queue config`](commands/config.md) — печатает настройки очереди; глобальный флаг `--root`.
- [`cy-queue submit`](commands/submit.md) — ставит в очередь команду CY или Hydra sweep.
- [`cy-queue worker`](commands/worker.md) — запускает ваши задания на GPU хоста.
- [`cy-queue list` и `tui`](commands/list.md) — состояния заданий, причины ожидания, интерактивный вид.
- [`cy-queue move`, `cancel`, `recover`, `archive`, `restore`](commands/jobs.md) — управление поставленными заданиями.
- [`cy-queue gpu`](commands/gpu.md) — список GPU, [удержание (hold)](../GLOSSARY.md#hold), освобождение GPU.

## Справочник

- [Конфигурация](configuration.md) — поиск файла, ключи `[queue]`, переменные окружения, ошибки конфигурации.

- [Формат вывода `--json`](formats/json.md) — записи, которые печатает каждая подкоманда с `--json`.
