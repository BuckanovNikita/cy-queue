# Domain documentation

This repository uses one root `GLOSSARY.md`, the
[product specification](../../specs/baseline.md) and the contract documents in `docs/`.

Before exploring a domain, read its glossary terms, the affected specification section
and [interfaces](../interfaces.md). Use the glossary's vocabulary in tickets, tests and
explanations. Surface conflicts with the specification explicitly.

If a referenced document is absent, continue without creating a placeholder. Follow the
[Linear and GitHub workflow](issue-tracker.md).
